# 🏠 Smart Home (UDP Console App)

Консольное приложение на C# — система "умного дома", работающая через UDP-сокеты.

---

## 🎯 Цель проекта

Проект создан для изучения:

- клиент-серверной архитектуры
- сетевого взаимодействия через UDP
- многопоточности в C#
- взаимодействия нескольких "устройств" в одной системе

---

## 🧰 Технологии

- C#
- .NET
- UDP (System.Net.Sockets)
- многопоточность (Thread)
- консольный интерфейс

---

## 🧠 Идея проекта

Система имитирует умный дом, где:

- есть центральный сервер
- есть клиент (панель управления)
- есть отдельные устройства (каждое как отдельный поток)
- устройства общаются через UDP-сообщения

---

## 🔐 Особенности реализации

- UDP-сокеты (без постоянного соединения)
- многопоточность (каждое устройство отдельно)
- простая система регистрации устройств
- обмен строковыми протоколами
- обработка состояния на сервере

---

## 🧪 Что реализовано в системе

- централизованный сервер управления
- несколько независимых устройств
- обмен командами в реальном времени
- получение состояния всех устройств
- консольный UI с навигацией

---

## 📌 Возможные улучшения

- переход на TCP или WebSocket
- GUI интерфейс (WPF / WinForms)
- нормальный JSON-протокол вместо строк
- авторизация устройств
- логирование в файл
- реконнект и устойчивость к потере пакетов
- масштабирование устройств

---

## 👨‍💻 Автор

Проект создан в учебных целях для изучения сетевого программирования и архитектуры клиент-серверных систем на C#.
